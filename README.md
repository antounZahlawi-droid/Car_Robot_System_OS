🚗 Car SystemOS
A macOS‑Inspired Web Interface for Controlling a Mobile Robot
Created by Antoun Bashar Zahlawi

Car SystemOS is a fully custom, interactive, macOS‑style control interface for a mobile robot.
It features draggable windows, real‑time sensor updates, a live camera feed, movement controls, sound effects, and a polished UI designed from scratch.

This project demonstrates advanced front‑end engineering, UI/UX design, and robotics integration — all built by an 11‑year‑old developer.

🌟 Features
🖥 macOS‑Style Window System
Draggable windows

Traffic‑light controls (close/minimize/fullscreen)

Smooth animations

Centered window positioning

macOS‑style error pop‑ups with shake animation

🎮 Robot Control Panel
Forward / Backward / Left / Right

Emergency stop

Refresh button with spin animation

Clean, responsive layout

📡 Real‑Time Sensor Dashboard
Four live sensor values

Auto‑updates every second

Optional error triggers for sensor failures

🎥 Camera Feed
Live video stream (placeholder)

Black fallback screen

Ready for real robot camera integration

🎵 Audio System
Background music toggle

Volume slider

macOS‑style UI

Basso error sound

⚙️ Sidebar Settings
Music on/off

Volume control

Mode settings (Controller / Bluetooth / WiFi)
